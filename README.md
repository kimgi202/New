# CRA Documant Manager

CRA를 위한 IRB 제출 추적 도구

## 특징
- 📋 IRB 제출/접수/승인 현황 관리
- 📅 제출기한 추적 (D-day)
- 📊 구분별 문서 관리
- 💾 자동저장
- 📥 CSV 내보내기

## 빠른 시작

### 방법 1: 이 템플릿으로 새 리포지토리 만들기
1. 이 페이지의 **"Use this template"** 클릭
2. 새 리포지토리 이름 입력
3. Railway에 배포 (아래 참고)

### 방법 2: Railway에 직접 배포
[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/new?template=https://github.com/kimgi202/New)

## 사용 방법
1. 프로젝트 추가
2. 기관(사이트) 추가
3. 섹션 추가 (초기심의, 변경보고 등)
4. 문서 추가 및 상태 관리
